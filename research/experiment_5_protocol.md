# Experiment 5 Protocol Specification: MinAtar Breakout Replication

## 1. Overview and Research Objective

The primary objective of this experiment is to independently reproduce and evaluate Experiment 5 from *"Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights"*:

> **Can a frontier Large Language Model directly program the weights of a neural network policy for MinAtar Breakout from scratch, using only a textual description of the game rules, source code, observation layout, and network architecture—without reinforcement learning, gradients, backpropagation, or environment feedback?**

This specification defines the exact, end-to-end reproducible protocol required to evaluate both the original reference weights (GPT-6 Astra) and candidate weights generated by Gemini Argon.

## 3. Environment Step Mechanics & Ordering

At each environment step $t$:
1. **Agent Action Selection:**
   - The agent receives the 600-element observation $x_t \in \{0, 1\}^{600}$.
   - The network computes logits:
     $$h_1 = \tanh(x_t \cdot W_1 + b_1)$$
     $$h_2 = \tanh(h_1 \cdot W_2 + b_2)$$
     $$\text{logits} = h_2 \cdot W_3 + b_3$$
   - Action probabilities are computed via numerically stable softmax:
     $$p_i = \frac{\exp(\text{logits}_i - \max(\text{logits}))}{\sum_j \exp(\text{logits}_j - \max(\text{logits}))}$$
   - An action $a_t \in \{0, 1, 2, 3, 4, 5\}$ is sampled from Categorical($p$).

2. **Sticky Action Resolution:**
   - A random uniform float $u \sim U(0, 1)$ is sampled.
   - If $u < 0.1$ and $t > 0$, the action executed is replaced by $a_{\text{exec}} = a_{\text{last}}$.
   - Otherwise, $a_{\text{exec}} = a_t$.
   - $a_{\text{last}} \leftarrow a_{\text{exec}}$.

3. **Game Mechanics Update Order (MinAtar Breakout):**
   - Step 3.1: **Paddle Update:**
     - If $a_{\text{exec}} = 1$ ('l'), paddle column $\text{pos} \leftarrow \max(0, \text{pos} - 1)$.
     - If $a_{\text{exec}} = 3$ ('r'), paddle column $\text{pos} \leftarrow \min(9, \text{pos} + 1)$.
     - Other actions ('n', 'u', 'd', 'f') do not move the paddle.
   - Step 3.2: **Ball Trajectory Update:**
     - Record previous coordinates: $\text{last}_x \leftarrow \text{ball}_x$, $\text{last}_y \leftarrow \text{ball}_y$.
     - Compute candidate position $(\text{new}_x, \text{new}_y)$ based on diagonal direction `ball_dir`.
   - Step 3.3: **Collision Resolution:**
     - Horizontal wall bounces: if $\text{new}_x < 0$ or $\text{new}_x > 9$, reflect horizontal direction.
     - Top wall bounce: if $\text{new}_y < 0$, reflect vertical direction.
     - Brick collisions: if $(\text{new}_y, \text{new}_x)$ hits an active brick, reward $+1$, brick destroyed, reflect vertical direction.
     - Paddle bounce: if $\text{new}_y = 9$, check if $\text{ball}_x == \text{pos}$ or $\text{new}_x == \text{pos}$; reflect accordingly.
     - Bottom boundary: if $\text{new}_y = 9$ and paddle missed, `terminal` $\leftarrow \text{True}$.
     - Brick regeneration: when all bricks are destroyed, a new set of 3 rows (rows 1, 2, 3) is spawned upon next paddle bounce.

## 4. Observation Mapping Specification

Native MinAtar Breakout provides 4 channels (`paddle: 0`, `ball: 1`, `trail: 2`, `brick: 3`).
The network input consists of 6 channels formatted into shape $(10, 10, 6)$:

$$\text{obs}[:, :, 0] = \text{native}[:, :, 0] \quad (\text{paddle})$$
$$\text{obs}[:, :, 1] = 0 \quad (\text{danger - empty in Breakout})$$
$$\text{obs}[:, :, 2] = \text{native}[:, :, 3] \quad (\text{reward / bricks})$$
$$\text{obs}[:, :, 3] = \text{native}[:, :, 1] \quad (\text{projectile / ball})$$
$$\text{obs}[:, :, 4] = \text{native}[:, :, 2] \quad (\text{trail / last ball pos})$$
$$\text{obs}[:, :, 5] = 0 \quad (\text{gauge - empty in Breakout})$$

Flattening is executed row-major:
$$\text{flat\_obs} = \text{obs}.\text{reshape}(-1)$$
Length is verified to be exactly 600.

## 5. Weight Edit Language & Parsing Specification

The model outputs its solution inside a Markdown code block tagged with `edits`:

````markdown
```edits
<statement_1>
<statement_2>
...
```
````

### Rules:
1. Target tensors: `W1` (600 × 32), `b1` (32), `W2` (32 × 32), `b2` (32), `W3` (32 × 6), `b3` (6).
2. Initial state: All tensors start at zero.
3. Grammar:
   - Single element assignment: `W1[i, j] = val`, `b1[i] = val`
   - Slicing and striding: `W1[start:end:step, j] = val` or `[v1, v2, ...]`
   - Multi-dimensional slicing: `W2[r_start:r_end, c_start:c_end] = [[...], [...]]`
   - Assignment operators: `=`, `+=`, `-=`, `*=`
   - Comments: Lines starting with `#` or inline `#` comments are ignored.
   - Ordering: Statements apply sequentially in appearance order; later statements overwrite earlier values.
   - Block selection: Only the **last** `edits` block in the model reply is evaluated.

### Safety Guarantee:
The parser MUST NOT use `eval()` or `exec()`. It parses Python AST nodes using `ast.parse` and interprets only mathematical assignment semantics over pre-allocated NumPy buffers.

## 6. Evaluation Protocol & Statistical Metrics

For each agent/weight checkpoint:
1. Initialize 1,000 episodes using seeds $S_1, \dots, S_{1000}$.
2. For each episode:
   - Reset environment with episode seed.
   - Step through environment until `terminal` is True or `step == 10,000`.
   - Accumulate total episode score and episode length.
3. Compute metrics:
   - Mean score: $\mu = \frac{1}{N} \sum_{i=1}^N R_i$
   - Standard Error: $\text{SE} = \frac{\sigma}{\sqrt{N}}$
   - Median, Min, Max score.
   - Mean episode length.
4. Save raw episode records to `results/episode_scores.csv` and summary metrics to `results/summary.json`.

## 7. Experimental Isolation & Gemini Argon Protocol

1. **Prompt Delivery:** Gemini Argon receives the exact byte-for-byte text in `gemini/experiment_prompt.txt`.
2. **One-Shot Requirement:** No multi-turn prompting, no iterative refinement, no evaluation feedback.
3. **Immutability:** Raw output is stored verbatim in `gemini/response_raw.txt`.
4. **Parsing:** The safe weight parser converts the raw response into `gemini/generated_weights.npz`.
5. **Evaluation:** The pre-frozen evaluation harness tests the weights under identical seeds and conditions without manual tuning.
