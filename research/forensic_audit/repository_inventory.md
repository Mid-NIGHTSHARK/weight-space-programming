## 3. Directory Layout and Verification Summary

The project consists of 8 primary modules:
1. `research/`: Experimental protocols, original prompts, and verification audit reports.
2. `gemini/`: Standalone utilities for prompt formatting and weight extraction.
3. `environment/`: MinAtar Breakout interface, action schema, and observation coordinate bijection.
4. `network/`: Neural network architecture, safe AST weight parser, weight loader, and stochastic inference.
5. `evaluation/`: Seed generation, episode execution, statistical analysis, and logging.
6. `baselines/`: Zero agent, random agent, and 10M-step PPO baseline implementation.
7. `experiments/`: Historical multi-seed evaluation runs, reference runs, and blind generation artifacts.
8. `tests/`: 67 automated unit and integration tests covering environment, architecture, parser, GUI, and reproducibility.

**Auditor Attestation:** Every critical file exists, matches expected cryptographic hashes, and shows no unauthorized post-hoc modifications.
